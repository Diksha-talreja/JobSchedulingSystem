# 🧮 Job Scheduling System (Java Swing)

This project is a **Job Scheduling System** built using **Java and Swing GUI**.  
It demonstrates the concept of **CPU job scheduling algorithms** and how they can be visualized and simulated using a graphical interface.

---

## 🚀 Features
- User-friendly **Java Swing interface**
- Supports different **scheduling algorithms** (like FCFS, SJF, Round Robin, etc.)
- Displays job execution order and waiting times
- Interactive input and output panels

---

## 🛠️ Technologies Used
- **Java (JDK 8 or later)**
- **Swing GUI Toolkit**
- **Object-Oriented Programming**
